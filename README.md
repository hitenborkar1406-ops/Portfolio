# Hiten Borkar — Portfolio

Personal portfolio website built with the [Hallmark](https://github.com/Nutlope/hallmark) design system (Cobalt theme).

**Live:** [View Portfolio](https://hitenborkar1406-ops.github.io/Portfolio/)

## Theme

**Cobalt** — cool near-white paper, blue-grey hairlines, Familjen Grotesk + IBM Plex Sans + JetBrains Mono, keycap buttons, one electric cobalt signal.

## Structure

```
├── index.html      # Single-page portfolio
├── tokens.css      # Cobalt theme design tokens
├── base.css        # Scaffold: floor rules, keys, cuts, graphite
├── style.css       # Page-specific styles + responsive
├── main.js         # Mobile nav toggle
├── favicon.svg     # SVG favicon
└── assets/
    └── avatar.jpg  # Profile image
```

## Sections

- **Hero** — headline, one-liner, CTA
- **Projects** — Smart IV Monitoring, CarbonTrack SME (live links)
- **Skills** — languages and tools as keycap buttons
- **Achievements** — Hacksagon 2026 (2nd/2100+), Ideathon (2nd runner up)
- **About** — education, research, blockchain chapter
- **Contact** — email, phone, GitHub, location

## Built with

- HTML, CSS, JavaScript (vanilla)
- Hallmark v2.0.0 design skill (Cobalt theme)
- No frameworks, no build tools
